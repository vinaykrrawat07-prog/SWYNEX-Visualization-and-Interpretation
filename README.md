# SWYNEX - Visualization and Interpretation

## 1. Project Overview
This project focuses on visualizing and interpreting biological data using charts and descriptive statistics.

## 2. Dataset
- **Organism:** Lactobacillus delbrueckii subsp. bulgaricus
- **Strain:** TCI904
- **Data Source:** NCBI
- **Assembly Accession:** GCF_040267765.1

## 3. Objectives
- Present biological data using appropriate charts.
- Explore genome assembly characteristics.
- Interpret patterns and trends supported by the data.
- Communicate findings clearly.

## 4. Planned Visualizations
- Genome size comparison, if comparable datasets are available.
- GC content comparison, if suitable data are available.
- Bar charts of relevant biological features, if supported by the dataset.
